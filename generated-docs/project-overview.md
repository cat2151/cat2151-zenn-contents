# Project Overview

## プロジェクト概要
- Zennへの投稿記事の草稿と修正履歴をGitHubで一元管理するためのリポジトリです。
- `published: false` の記事を草稿として、`published: true` 後も修正版を管理します。
- ZennとGitHubの連携機能を利用し、無料公開記事のバージョン管理を行います。

## 技術スタック
- フロントエンド: なし（このプロジェクトはコンテンツ管理が主目的です）
- 音楽・オーディオ: なし（音楽・オーディオは記事のテーマであり、プロジェクトの技術スタックではありません）
- 開発ツール:
    - Zenn CLI: Zennの記事をローカルで作成、プレビュー、管理するためのコマンドラインツールです。
    - Git: ソースコードのバージョン管理システムで、変更履歴の追跡や複数人での共同作業に利用されます。
    - GitHub: Gitリポジトリをホストし、バージョン管理されたコンテンツを公開・共有するためのプラットフォームです。Zennとの連携に使用されます。
- テスト: なし（テストフレームワークや関連ツールは使用されていません）
- ビルドツール:
    - Zenn CLI: Markdown形式の記事ファイルをZennプラットフォームで表示可能な形式に変換したり、ローカルプレビューを生成したりする機能を持つため、広義のビルドツールとして機能します。
- 言語機能:

- 自動化・CI/CD: なし（明示的な自動化や継続的インテグレーション/デリバリーの仕組みは導入されていません）
- 開発標準: なし（特定のコーディング規約や品質ツールは明示されていません）

## ファイル詳細説明
- **`.gitignore`**: Gitのバージョン管理システムが追跡しないファイルやディレクトリを指定します。これにより、不要なファイルがリポジトリに含まれるのを防ぎます。
- **`README.md`**: プロジェクトの目的、使い方、Zennとの連携方法など、プロジェクトに関する概要情報が記載されています。来訪者が最初に参照するファイルです。
- **`_config.yml`**: Zennの全体設定ファイルです。Zennの公開設定や表示に関するメタデータなどが記述される可能性があります。（現状は空ですが、Zennの機能拡張時に使用されます。）
- **`articles/`**: Zennの個別の記事（Article）のMarkdownファイルを格納するためのディレクトリです。
    - **`.keep`**: `articles`ディレクトリが空の場合でもGitがディレクトリ構造を保持するためのプレースホルダーファイルです。
    - **`github-zenn-linkage-20240217.md`**: GitHubとZennの連携に関するZenn記事の草稿（Markdown形式）です。
    - **`github-zenn-linkage-20260316.md`**: GitHubとZennの連携に関する別のZenn記事の草稿（Markdown形式）です。
- **`books/`**: Zennの複数の記事をまとめて書籍形式で公開するBookコンテンツのファイルを格納するためのディレクトリです。
    - **`.keep`**: `books`ディレクトリが空の場合でもGitがディレクトリ構造を保持するためのプレースホルダーファイルです。
- **`generated-docs/`**: Zenn CLIによって生成されるドキュメントやプレビュー用のファイルが配置されるディレクトリです。（現状は空です。）
- **`package-lock.json`**: プロジェクトの依存関係（`package.json`で定義）の正確なバージョンとツリー構造を記録します。これにより、異なる環境でも同じ依存関係のセットがインストールされることが保証されます。
- **`package.json`**: プロジェクトのメタデータ（名前、バージョンなど）や、プロジェクトが依存する外部ライブラリ（この場合は`zenn-cli`）および実行可能なスクリプトを定義するファイルです。
