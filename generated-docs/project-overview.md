# Project Overview

## プロジェクト概要
- Zennに投稿する記事の草稿や公開済み記事の変更履歴を一元管理するリポジトリです。
- `published: false`のドラフト状態から公開後の記事修正まで、GitHubでバージョン管理を行います。
- 主に無料公開される技術記事やノウハウのコンテンツを、透明性の高い方法で維持します。

## 技術スタック
- フロントエンド: Zennプラットフォーム (記事のレンダリングと公開を担うプラットフォームを利用します。本プロジェクトでは直接的なフロントエンド開発は行いません。)
- 音楽・オーディオ: (このカテゴリは記事コンテンツの主要なテーマですが、直接的な技術スタックとしては使用されていません。プロジェクトで扱う記事の分野を示します。)
- 開発ツール:
    - Zenn CLI: Zenn記事の新規作成 (`npx zenn new:article`)、ローカルでのプレビュー (`npx zenn preview`)、およびGitHub連携を支援するコマンドラインツールです。
    - Node.js: Zenn CLIの実行環境として使用されます。
- テスト: (特定のテストツールは使用されていません。コンテンツの検証は主にプレビューで行われます。)
- ビルドツール: Zenn CLI (MarkdownコンテンツをZennプラットフォーム向けの記事形式に変換し、プレビュー機能を提供します。)
- 言語機能: Markdown (Zenn記事の記述に使用される軽量マークアップ言語です。)
- 自動化・CI/CD: (特定のCI/CDパイプラインは設定されていませんが、GitHubリポジトリとZennプラットフォームの連携により、公開記事の自動デプロイが可能です。)
- 開発標準: (Zennのコンテンツ規約およびGitHubリポジトリの一般的な慣習に従います。コード品質ツールなどは使用されていません。)

## ファイル詳細説明
- `.gitignore`: Gitのバージョン管理から除外するファイルやディレクトリを指定する設定ファイルです。ビルド生成物や一時ファイルなどが含まれます。
- `README.md`: プロジェクトの概要、目的、セットアップ方法、使い方などを記述したファイルです。このリポジトリの主要な情報源となります。
- `_config.yml`: Zennのコンテンツに関する設定（例えば、コンテンツのメタ情報やプラットフォーム固有の動作設定）を記述するYAML形式の設定ファイルです。
- `articles/`: Zennに投稿する個々の記事（Markdown形式）を格納するためのディレクトリです。
    - `.keep`: 空のディレクトリをGitで管理するためのプレースホルダーファイルです。
    - `github-zenn-linkage-20240217.md`: GitHubとZennの連携に関する記事のMarkdownファイルです。草稿または公開済み記事のバージョン管理対象となります。
    - `github-zenn-linkage-20260316.md`: GitHubとZennの連携に関する別記事のMarkdownファイルです。上記と同様にバージョン管理されます。
- `books/`: Zennの「本」（複数の記事をまとめたシリーズ）を構成するファイルを格納するためのディレクトリです。
    - `.keep`: 空のディレクトリをGitで管理するためのプレースホルダーファイルです。
- `generated-docs/`: プロジェクトのドキュメントやその他の自動生成される成果物を格納すると想定されるディレクトリです。
- `package-lock.json`: `package.json`で定義された依存関係の正確なバージョンと、その依存関係ツリーをロックするファイルです。これにより、異なる環境間での依存関係の一貫性が保たれます。
- `package.json`: プロジェクトのメタデータ（名前、バージョン）および、プロジェクトが依存するパッケージ（例: `zenn-cli`）を定義するファイルです。

## 関数詳細説明
このプロジェクトは主にZennのコンテンツ（Markdownファイル）を管理するものであり、ユーザーが独自に定義したプログラミング言語の関数は含まれていません。Zenn CLIのコマンド（例: `npx zenn new:article` や `npx zenn preview`）は利用しますが、これらは外部ツールによって提供される機能であり、本プロジェクトのコード内で定義される関数ではありません。
