# Project Overview

## プロジェクト概要
- Zennに投稿する記事コンテンツをGitHubで管理するためのリポジトリです。
- 公開前の草稿から公開後の記事修正まで、一貫した版管理を実現します。
- ZennのGitHub連携機能を活用し、無料記事を公開リポジトリで効率的に管理します。

## 技術スタック
- フロントエンド: このプロジェクトはMarkdownベースのコンテンツ管理であり、特定のフロントエンド技術は使用していません。コンテンツはZennプラットフォーム上でレンダリングされます。
- 音楽・オーディオ: プロジェクト自体では使用されていませんが、投稿候補の記事テーマとして「音楽関連」が挙げられています。
- 開発ツール:
    - Zenn CLI: Zennコンテンツの作成、プレビュー、GitHub連携のサポートを行います。
    - npm/npx: Node.jsのパッケージ管理ツールであり、Zenn CLIの実行環境として使用されます。
- テスト: このプロジェクトには明示的なテスト関連技術は含まれていません。
- ビルドツール: Zenn CLIがコンテンツのプレビュー機能を提供しますが、一般的なWebアプリケーションのビルドツールとは異なります。
- 言語機能:
    - Markdown: Zenn記事のコンテンツ記述に使用される軽量マークアップ言語です。
    - YAML: 各記事ファイルの冒頭に記述されるフロントマター（メタデータ）の定義に使用されます。
    - JavaScript/Node.js: Zenn CLIがNode.js環境で動作するため、間接的に使用されます。
- 自動化・CI/CD:
    - GitHub: プロジェクトのリポジトリ管理、バージョン管理、Zennとの連携基盤として利用されます。
    - Zenn GitHub連携: GitHubリポジトリの更新を検知し、Zennプラットフォームへ自動的にコンテンツを同期・公開する仕組みです。
- 開発標準: ZennのMarkdown記法ガイドラインに従ってコンテンツが作成されます。

## ファイル詳細説明
- **`.gitignore`**: Gitのバージョン管理から除外するファイルやディレクトリを指定するための設定ファイルです。ビルド生成物や一時ファイルなどを管理対象外とします。
- **`README.md`**: プロジェクトの概要、目的、使い方、そしてZennとの連携方法など、プロジェクトに関する基本的な情報を提供する主要なドキュメントファイルです。
- **`_config.yml`**: ZennのGitHub連携における設定を定義するファイルです。例えば、デフォルトの公開設定やスラッグ生成ルールなどを記述する場合があります。
- **`articles/`**: Zennに投稿する個々の記事（チャプターではない単体の記事）のMarkdownファイルを格納するためのディレクトリです。
    - **`.keep`**: `articles`ディレクトリが空の場合でもGitに追跡させるために配置されるプレースホルダーファイルです。
    - **`github-zenn-linkage-20240217.md`**: Zennに投稿される具体的な記事コンテンツのMarkdownファイルです。GitHubとZennの連携方法に関する内容が含まれます。
    - **`github-zenn-linkage-20260316.md`**: Zennに投稿される具体的な記事コンテンツのMarkdownファイルです。上記と同様にGitHubとZennの連携方法に関する内容が含まれます。
- **`books/`**: Zennで「本」として公開する、複数の記事をまとめたコンテンツのMarkdownファイルや設定ファイルを格納するためのディレクトリです。
    - **`.keep`**: `books`ディレクトリが空の場合でもGitに追跡させるために配置されるプレースホルダーファイルです。
- **`generated-docs/`**: Zenn CLIによって生成されるプレビュー用のファイルや一時的なドキュメントが格納される可能性があるディレクトリです。
- **`package-lock.json`**: `package.json`に記載されている依存パッケージの正確なバージョンと依存関係ツリーを記録し、ビルドの再現性を保証するためのファイルです。
- **`package.json`**: プロジェクトのメタデータ（名前、説明など）と、依存するnpmパッケージ（このプロジェクトでは`zenn-cli`）を定義するファイルです。スクリプトや開発依存関係もここに記述されます。

## 関数詳細説明
このプロジェクトは主にZenn記事のコンテンツ管理を目的としており、特定のユーザー定義関数は含まれていません。Zenn CLIのコマンド（`zenn new:article`, `zenn preview`など）が使用されますが、これらはZenn CLIツールによって提供される機能であり、このプロジェクト内で定義された関数ではありません。
